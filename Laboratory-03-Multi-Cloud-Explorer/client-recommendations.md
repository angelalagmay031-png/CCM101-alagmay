# 🎯 Client Recommendations

### Client A – Startup

**Recommended: AWS**

AWS is suitable because a startup can begin with relatively small resources and scale as demand increases. Useful services include **EC2, S3, and RDS**.

### Client B – University

**Recommended: Azure**

Azure is the best fit because the university already uses Windows Server, Microsoft 365, and Active Directory. Useful services include **Azure Virtual Machines, Microsoft Entra ID, and Azure SQL Database**.

### Client C – AI Research Company

**Recommended: GCP**

GCP is recommended because of its strong AI/ML and data-processing capabilities. Useful services include **Compute Engine, Vertex AI, and Google Kubernetes Engine**.

### Client D – Global E-Commerce

**Recommended: AWS**

AWS is appropriate for a global e-commerce application because it provides scalable compute, storage, databases, and networking. Useful services include **EC2, S3, and Auto Scaling**.
