# 🔴 Google Cloud Platform (GCP)

## Overview

Google Cloud provides services for computing, storage, databases, analytics, AI, networking, and application development.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones where applications and resources can operate.

## Management Console

Google Cloud Console is a web interface used to manage Google Cloud projects and resources.

## Four Core Services

| Category   | GCP Service              |
| ---------- | ------------------------ |
| Compute    | Compute Engine           |
| Storage    | Cloud Storage            |
| Database   | Cloud SQL                |
| Kubernetes | Google Kubernetes Engine |

## Advantages

1. Strong AI and machine-learning capabilities.
2. Excellent Kubernetes support.
3. Strong data analytics ecosystem.

## Enterprise Uses

GCP can support AI research, data analytics, web applications, containers, Kubernetes, and large-scale data processing.
