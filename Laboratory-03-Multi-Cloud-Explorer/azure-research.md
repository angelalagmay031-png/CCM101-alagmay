# 🔵 Microsoft Azure

## Overview

Microsoft Azure is Microsoft's cloud platform for computing, storage, databases, networking, AI, security, and enterprise applications.

## Global Infrastructure

Azure provides cloud infrastructure across a global network of regions and data centers.

## Management Console

The Azure Portal is a web-based management interface for creating and managing Azure resources.

## Four Core Services

| Category | Azure Service          |
| -------- | ---------------------- |
| Compute  | Azure Virtual Machines |
| Storage  | Azure Blob Storage     |
| Database | Azure SQL Database     |
| Identity | Microsoft Entra ID     |

## Advantages

1. Strong Microsoft integration.
2. Good enterprise and hybrid-cloud capabilities.
3. Broad AI and machine-learning services.

## Enterprise Uses

Azure is suitable for Microsoft-based organizations, enterprise applications, hybrid infrastructure, databases, and AI solutions.
