# 🟠 Amazon Web Services (AWS)

## Overview

AWS is a major cloud platform launched in 2006. It provides cloud services including computing, storage, databases, networking, security, and AI.

## Global Infrastructure

AWS operates a worldwide infrastructure consisting of geographic Regions and Availability Zones.

## Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services.

## Four Core Services

| Category   | AWS Service |
| ---------- | ----------- |
| Compute    | Amazon EC2  |
| Storage    | Amazon S3   |
| Database   | Amazon RDS  |
| Networking | Amazon VPC  |

## Advantages

1. Very broad range of cloud services.
2. Highly scalable infrastructure.
3. Pay-as-you-go cloud model.

## Enterprise Uses

AWS can be used for web applications, databases, storage, analytics, AI, backup, and large-scale enterprise systems.
