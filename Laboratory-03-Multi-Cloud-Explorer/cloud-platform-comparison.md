## Questions

**1. Which provider offers the broadest range of services?**
AWS offers the broadest range of services. Its portfolio covers computing, storage, databases, networking, security, AI, analytics, and many other categories.

**2. Which provider best integrates with Microsoft technologies?**
Azure is the strongest choice because it is designed around Microsoft's ecosystem and enterprise technologies.

**3. Which provider is strongest in AI and Kubernetes?**
GCP is a strong choice because it provides extensive AI services and Google Kubernetes Engine.

**4. Which would I choose?**
I would choose AWS because it provides a very broad selection of services and can support different types of workloads.
