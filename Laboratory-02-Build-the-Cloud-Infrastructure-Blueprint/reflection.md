
# Mission Reflection

### 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the **server** is the most important cloud infrastructure component because it is where applications, services, and other processes run. It provides the computing resources needed to handle tasks and serve users. Without a reliable server, the other parts of the cloud infrastructure would not be able to work properly.

### 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, secure, flexible, and efficient operating system for cloud servers. It can run using fewer resources and provides powerful command-line tools for managing servers. During the laboratory, I used Linux commands to check the server's CPU, RAM, storage, network, and other system information.

### 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it serves as a guide for setting up and managing infrastructure. It records important information such as configurations, resources, and network details. Good documentation can prevent errors, make troubleshooting easier, and help other people understand the system.

### 4. What new skills did you learn during this laboratory activity?

I learned how to use Linux commands to investigate a cloud server. I practiced checking the operating system, kernel version, CPU, RAM, disk capacity, mounted file systems, hostname, and IP address. I also improved my ability to organize technical information and document my findings properly.

### 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I was able to add actual laboratory work, technical reports, and documentation. It now provides evidence of the skills I practiced instead of only showing written activities. This makes my portfolio more useful because it demonstrates my experience with Linux, cloud infrastructure, and technical documentation.
