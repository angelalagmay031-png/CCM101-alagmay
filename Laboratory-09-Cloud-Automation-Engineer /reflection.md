
# Checkpoint 7 – Mission Reflection

After completing Laboratory Activities 1 to 9, I realized that Cloud Computing involves more than simply using online storage or accessing applications through the internet. Each activity introduced me to a different part of cloud operations, from preparing infrastructure and running containers to protecting systems and automating administrative tasks. My understanding became clearer because I was able to perform these activities using actual Linux commands and tools.

Automation is important when managing hundreds of cloud servers because performing the same operations manually takes too much time. Scripts allow administrators to complete repeated tasks more consistently. However, automation can also cause serious problems if it is not properly checked. For example, a small destructive command scheduled across 1,000 servers could delete important files or interrupt services on every affected machine. Testing and reviewing scripts before deployment is therefore necessary.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash focuses on executing commands and controlling the steps of a process, while Docker Compose describes how containers, networks, and services should be configured. Both are useful, but they solve different problems.

Looking back at my GitHub portfolio, I can see my progress from learning basic cloud concepts to performing practical administration tasks. I now have a better understanding of infrastructure, virtualization, containerization, storage, deployment, monitoring, security, and automation.

The role I enjoyed most was Cloud Automation Engineer because I found it interesting that a few lines of code could perform a task repeatedly without requiring someone to operate the terminal every time. Creating the backup script and scheduling it with Cron showed me how useful automation can be in protecting important data.

This mission taught me that a good cloud engineer should not only know how to operate systems but also find better and safer ways to manage them. I still have more to learn, but I am more confident in handling basic cloud operations than when I started this semester.
