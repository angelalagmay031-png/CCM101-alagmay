# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focused on deploying and managing an object storage server using MinIO and Docker. The mission demonstrated how object storage can be used to store and manage uploaded files through a web-based console.

## Objectives

- Understand the purpose and benefits of object storage.
- Deploy a MinIO server using Docker.
- Configure the MinIO API and Web Console ports.
- Set administrator credentials using environment variables.
- Create a storage bucket named `client-photos`.
- Upload and manage objects through the MinIO Object Browser.
- Verify that the Docker container is running successfully.
- Document the deployment process and technical configuration.

## Tools Used

- **KillerCoda Ubuntu Playground** - Provided the Linux terminal environment.
- **Docker** - Used to download and run the MinIO container image.
- **MinIO Community Edition** - Provided the S3-compatible object storage server and web console.
- **MinIO Object Browser** - Used to create the `client-photos` bucket and upload files.
- **GitHub** - Used to store and document the laboratory deliverables using Markdown.

## Skills Learned

- Deploying containerized applications in a Linux environment.
- Configuring Docker port mappings for application access.
- Using environment variables to configure application credentials.
- Verifying container status with `docker ps` and `docker inspect`.
- Understanding object storage buckets and uploaded objects.
- Managing files through a web-based storage console.
- Writing technical documentation using Markdown.
- Troubleshooting container image access and deployment issues.
